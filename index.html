HealthBot

  • LangGraph
  • LangChain
  • Tavily
  • Mistral AI

A patient education assistant built as a multi-step LLM workflow with stateful nodes and conditional routing. It takes a health topic, retrieves current medical information through Tavily search, and has Mistral AI write a patient-friendly summary.

A comprehension-check loop then generates a quiz question, grades the patient’s answer and explains it with reference to the summary. Graph state survives input pauses, topic restarts and exit.
